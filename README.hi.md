# GlyphStudio

एक स्थिर और गतिशील छवियों, विविधताओं, पुन: प्रयोज्य भागों और संरचित आउटपुट के लिए एक नियंत्रित पिक्सेल संपत्ति स्टूडियो।

GlyphStudio एक डेस्कटॉप एप्लिकेशन है जिसे **Tauri v2**, **React**, और **Rust** का उपयोग करके बनाया गया है। यह एक **MCP सर्वर** के साथ आता है जो LLM को पूरी स्प्राइट संपादन सतह प्रदान करता है - समान डोमेन लॉजिक, समान पिक्सेल बफर, समान पूर्ववत/पुनरावृत्ति।

## आप क्या कर सकते हैं

**बनाएं** - नियतात्मक उपकरणों, परतों और पैलेट नियंत्रण के साथ पिक्सेल कला बनाएं।

**एनिमेट करें** - प्याज की त्वचा, समय निर्धारण और उत्तम गुणवत्ता वाले उपकरणों के साथ फ्रेम-दर-फ्रेम गति बनाएं।

**विविधता** - संपत्तियों को नामित दस्तावेज़ विविधताओं (दिशात्मक, मुद्रा) और पैलेट विविधताओं (पुन: रंग परिवार) में विभाजित करें। प्रतिबद्ध करने से पहले पूर्वावलोकन करें।

**पुन: उपयोग करें** - चयन को पुन: प्रयोज्य भागों में बढ़ावा दें। क्यूरेटेड पैक सहेजें। भागों को परियोजनाओं में स्टैंप करें।

**बंडल करें** - एक ही बार में संपत्ति परिवारों को निर्यात करें: आधार + दस्तावेज़ विविधताएं + पैलेट विविधताएं, प्रासंगिक फ़ाइल नामों के साथ।

**तेजी से शुरू करें** - टेम्पलेट्स, पैक्स या शुरुआती व्यंजनों से शुरू करें। फ्रंट डोर उन वर्कफ़्लो को दर्शाता है जिनका स्टूडियो समर्थन करता है।

## सर्वश्रेष्ठ वर्कफ़्लो

### स्थिर स्प्राइट
खाली परियोजना (32x32) → पेंसिल/भर/इरेज़र से बनाएं → पैलेट कार्यक्षेत्र → PNG निर्यात करें।

### एनिमेटेड लूप
खाली परियोजना (32x32, 4 फ्रेम) → फ्रेम 1 बनाएं → डुप्लिकेट + संपादित करें → संरेखण के लिए प्याज की त्वचा → समय निर्धारण → GIF या स्ट्रिप निर्यात।

### विविधता परिवार
आधार संपत्ति बनाएं → दस्तावेज़ विविधताएं (जैसे, बाएं ओर चलें, दाएं ओर चलें) → पैलेट सेट बनाएं (जैसे, आग, बर्फ) → पैलेट रीमैप का पूर्वावलोकन करें → `{name}-{variant}-{palette}.png` फ़ाइल नामों के साथ बंडल निर्यात।

### पुन: प्रयोज्य भाग
एक आवर्ती रूप बनाएं → चुनें → भाग में बढ़ावा दें → लाइब्रेरी में सहेजें → अन्य फ़्रेम/परियोजनाओं में स्टैंप करें। क्रॉस-परियोजना पुन: उपयोग के लिए क्यूरेटेड भागों + पैलेट को एक पैक के रूप में सहेजें।

### टेम्पलेट/पैक प्रारंभ
ProjectHome → एक टेम्पलेट (एनीमेशन-तैयार या विविधता-तैयार) या पैक (UI किट, पैलेट संग्रह) चुनें → पहले से लोड संरचना के साथ कार्य परियोजना।

## मुख्य अवधारणाएं

| अवधारणा | यह क्या है | यह कहाँ स्थित है |
|---------|-----------|----------------|
| **Palette Set** | पुन: रंग के लिए रंगों का एक नामित सेट | दस्तावेज़-स्तर, स्विच करने योग्य |
| **Document Variant** | फ्रेम अनुक्रम का एक विभाजन (मुद्रा, दिशा) | दस्तावेज़-स्तर, स्वतंत्र फ्रेम |
| **Part** | एक पुन: प्रयोज्य पिक्सेल स्टैंप जिसे चयन से बढ़ावा दिया गया है | लाइब्रेरी, क्रॉस-परियोजना |
| **Pack** | पैलेट सेट + भागों का एक क्यूरेटेड बंडल | लाइब्रेरी, आयात करने योग्य/निर्यात करने योग्य |
| **Template** | एक परियोजना-प्रारंभ खाका (कैनवास, पैलेट, फ्रेम) | लाइब्रेरी, ProjectHome से उपयोग किया जाता है |
| **Bundle** | आधार + विविधताएं + पैलेट का एक-पास निर्यात | निर्यात प्रवाह |
| **Interchange** | परियोजनाओं के बीच निर्मित संरचनाओं को स्थानांतरित करने के लिए JSON प्रारूप | `.interchange.json` फाइलें |

## प्रासंगिक शॉर्टकट

GlyphStudio आपके द्वारा किए जा रहे कार्य के आधार पर प्रासंगिक शॉर्टकट दिखाता है। संदर्भ बदलने पर पट्टी अपडेट होती है।

| संदर्भ | मुख्य शॉर्टकट |
|---------|--------------|
| **Drawing** | `B` पेंसिल, `E` इरेज़र, `G` भरें, `M` मार्की, `X` FG/BG स्वैप करें, `Ctrl+Z` पूर्ववत करें |
| **Selection active** | `Ctrl+C` कॉपी करें, `Ctrl+X` काटें, `Ctrl+V` पेस्ट करें, `Del` साफ़ करें, `Esc` अचयनित करें |
| **Stamp mode** | `Click` स्टैंप रखें, `Esc` बाहर निकलें |
| **Animation** | `Ctrl+D` फ्रेम डुप्लिकेट करें, `Space` चलाएं/रोकें, `Left/Right` फ्रेम बढ़ाएं |
| **Library focused** | `Ctrl+F` खोजें, `Up/Down` नेविगेट करें, `Enter` सक्रिय करें |
| **Variant workflow** | `+ Variant` अनुक्रम विभाजित करें, `Toggle` तुलना ओवरले |
| **Palette preview** | `Apply` रीमैप प्रतिबद्ध करें, `Cancel` त्यागें |

## आर्किटेक्चर

### फ्रंटएंड (React + TypeScript)
- डोमेन द्वारा व्यवस्थित Zustand स्टोर
- HTML कैनवास रेंडरर
- फ्रंटएंड-स्वामित्व वाले पिक्सेल बफ़र और अल्फा कंपोजिटिंग के साथ स्प्राइट संपादक
- एकीकृत सूचकांक, खोज, पिनिंग और कीबोर्ड नेविगेशन के साथ लाइब्रेरी पैनल

### बैकएंड (Rust)
- आधिकारिक पिक्सेल बफ़र और लेयर कंपोजिटिंग
- पूर्ववत/पुनरावृत्ति के साथ स्ट्रोक लेनदेन
- परियोजना दृढ़ता, ऑटोसेव, क्रैश रिकवरी
- निर्यात पाइपलाइन (PNG, स्प्राइट शीट, एनिमेटेड GIF, बंडल)
- कैमरे और प्लेबैक के साथ दृश्य रचना इंजन

### MCP सर्वर (Node.js)
- प्रति सत्र हेडलेस Zustand स्टोर (कोई React, कोई ब्राउज़र नहीं)
- `@modelcontextprotocol/sdk` के माध्यम से पंजीकृत 76 उपकरण
- डेस्कटॉप ऐप के समान `@glyphstudio/domain` और `@glyphstudio/state` कोड
- stdio पर चलता है - क्लाउड डेस्कटॉप, क्लाउड कोड या किसी भी MCP क्लाइंट के साथ काम करता है

संपूर्ण उपकरण सूची के लिए [MCP सर्वर README](packages/mcp-sprite-server/README.md) देखें।

## ऐप चलाना

### आवश्यकताएं
- Node.js 20+
- pnpm 9+
- Rust 1.75+ (via [rustup](https://rustup.rs/))
- आपके प्लेटफ़ॉर्म के लिए Tauri v2 आवश्यकताएं

### स्थापित करें

```bash
pnpm install
```

### डेस्कटॉप ऐप चलाएं

```bash
pnpm dev
```

### एमसीपी सर्वर चलाएं (स्वतंत्र)

```bash
npx tsx packages/mcp-sprite-server/src/cli.ts
```

### टाइपचेक

```bash
pnpm typecheck
```

### परीक्षण

```bash
pnpm test
```

### रस्ट चेक

```bash
cd apps/desktop/src-tauri
cargo check
cargo test
```

## निर्यात समर्थन

| लक्ष्य | प्रारूप |
|--------|---------|
| **Single frame** | पीएनजी (संयुक्त दृश्य परतें) |
| **Animation** | एनिमेटेड जीआईएफ, पीएनजी अनुक्रम, स्प्राइट पट्टी |
| **Sheet** | मैनिफेस्ट के साथ स्प्राइट शीट (देशी + सामान्य रनटाइम) |
| **Bundle** | फ़ोल्डर या ज़िप जिसमें छवियां, मैनिफेस्ट और पूर्वावलोकन शामिल हैं |
| **Variant family** | आधार + दस्तावेज़ विविधताएं + प्रासंगिक फ़ाइल नामों के साथ पैलेट विविधताएं |
| **MCP Server** | Base64-encoded पीएनजी, शीट, जीआईएफ और मेटाडेटा जेएसओएन |

निर्यात केवल संयुक्त दृश्य परतों का उपयोग करते हैं। संपादक ओवरले (प्याज की त्वचा, प्लेबैक स्थिति) को कभी भी आउटपुट में शामिल नहीं किया जाता है।

## उत्पाद दर्शन

1. **निश्चित संपादन** — प्रत्येक पिक्सेल परिवर्तन वैध, निरीक्षण योग्य और प्रतिवर्ती है।
2. **अधीनस्थ एआई** — स्वचालन रचनात्मक नियंत्रण को प्रतिस्थापित किए बिना वर्कफ़्लो में सहायता करता है।
3. **एनीमेशन-प्रथम संरचना** — फ्रेम, टाइमलाइन, प्याज की त्वचा और प्लेबैक मुख्य अवधारणाएं हैं, बाद में जोड़े गए तत्व नहीं।
4. **विश्वसनीय स्थिति** — सहेजें/लोड करें, ऑटोसेव, पूर्ववत/फिर से करें और माइग्रेशन को उत्पाद सुविधाओं के रूप में माना जाता है।
5. **ईमानदार पुन: उपयोग** — भागों को मुहरित किया जाता है (प्रतिबद्ध पिक्सेल), नकली लिंक किए गए उदाहरण नहीं। विविधताएं शाखाएं हैं, छिपी हुई साझा स्थिति नहीं। प्रतिबद्ध करने से पहले पूर्वावलोकन करें।

## गैर-लक्ष्य

GlyphStudio का उद्देश्य निम्नलिखित नहीं है:

- एक सामान्य छवि संपादक
- एक ब्राउज़र-प्रथम खिलौना ऐप
- एक एआई प्रॉम्प्ट रैपर जो कला का अनुमान लगाता है
- एक अस्पष्ट कैनवास जहां फ्रंटएंड स्थिति और बैकएंड सत्य अलग हो जाते हैं
- एक नकली रिगिंग/प्रतीक प्रणाली जो लिंकेज होने का दिखावा करती है

## सुरक्षा

GlyphStudio एक **केवल डेस्कटॉप** एप्लिकेशन है। कोई नेटवर्क अनुरोध नहीं, कोई टेलीमेट्री नहीं, कोई गुप्त जानकारी नहीं।

- **उपयोग किया गया डेटा:** स्थानीय स्प्राइट फ़ाइलें (.ग्लाइफ, .पीएक्सएस, .पीएनजी), ऑटोसेव/रिकवरी फ़ाइलें
- **उपयोग नहीं किया गया डेटा:** कोई नेटवर्क नहीं, कोई क्लाउड नहीं, कोई रिमोट एपीआई नहीं, कोई उपयोगकर्ता खाता नहीं
- **अनुमतियाँ:** फ़ाइल सिस्टम एक्सेस, टाउरी v2 देशी फ़ाइल संवादों के माध्यम से उपयोगकर्ता द्वारा चुने गए निर्देशिकाओं तक सीमित

एमसीपी सर्वर बिना किसी नेटवर्क आउटपुट के स्थानीय रूप से एसटीडीआईओ पर चलता है। भेद्यता रिपोर्टिंग के लिए [सुरक्षा.एमडी](SECURITY.md) देखें।
